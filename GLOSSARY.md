# SnipNote

SnipNote turns a recorded meeting into a transcript, a summary and action items. Part of the product is free forever and part is paid, and this glossary fixes the vocabulary for that split.

## Language

**Local mode**:
Transcription and analysis that run on the user's device and cost the user nothing. It never consumes Minutes and is free forever.
_Avoid_: Free mode, on-device mode, offline mode

**Cloud mode**:
Transcription and analysis processed by SnipNote's servers, paid for with Minutes. It is the paid tier.
_Avoid_: Server mode, premium mode, Pro mode

**Guest**:
A user of Local mode who has no Account. SnipNote does not know who a Guest is.
_Avoid_: Anonymous user, free user

**Account**:
A user's identity with SnipNote, created with an email the first time they enter Cloud mode. Local mode never requires one.
_Avoid_: Login, profile, sign-up

**Minutes**:
The prepaid currency spent only by Cloud mode, in whole minutes of audio. Minutes never expire.
_Avoid_: Credits, tokens, balance (use "Minutes balance" for the amount held)

**Free-forever promise**:
SnipNote's commitment that Local mode is never limited, capped or paywalled. Only Cloud mode and clearly extra features may be paid.
_Avoid_: Free tier (this implies limits)

**Trial grant**:
The one-time allotment of Minutes given to a new user so they can try Cloud mode.
_Avoid_: Free minutes, free tier

**Pro**:
An Account holder with a positive Minutes balance, whether the Minutes were bought or came from the Trial grant. Everyone who creates an Account starts as Pro. Pro gets cross-device sync, the web app and, once built, speaker labels. This definition is provisional until the Subscription and pack lineup is redesigned.
_Avoid_: Premium, paid user

**Subscription**:
A recurring purchase that credits Minutes on each billing period.
_Avoid_: Plan

**Minutes pack**:
A one-time purchase that credits a fixed amount of Minutes.
_Avoid_: Top-up, bundle
